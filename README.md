# 戰艦對決 · Battleship P2P

雙人連線戰艦遊戲。純前端，瀏覽器對瀏覽器直連（WebRTC），沒有後端要養。
開一間房，把連結丟給朋友，隔著網路互相轟。

## 功能

- 10×10 棋盤、5 艘船（5/4/3/3/2 格）；勾選海克斯大亂鬥後棋盤變成 15×15
- 拖曳或點擊擺船，`R` / 右鍵 / 按鈕旋轉，一鍵隨機部署
- 輪流開火，命中 / 落空 / 擊沉即時回報 + 音效（Web Audio 合成，無音檔）
- 變體規則：命中後可以再開一槍（房主設定）
- 觀戰模式：第三人以上用同一個連結勾「觀戰」進來看
- 大廳背景是一段夕陽下兩艦對峙的動畫（`assets/lobby.mp4`）。60KB 的 poster 先頂著、影片載好再淡入；省流量模式、偏好減少動態、窄螢幕則只顯示靜圖不下載影片，離開大廳會自動暫停
- 聊天室、戰報、終局揭曉雙方船位、再來一局
- **⚡ 海克斯大亂鬥**（房主在擺船階段勾選，勾選欄下方會即時顯示這場預估要打多久）：棋盤變成 **15×15＝225 格**，編制整個換成 **10 艘船**——先擺 9 艘（5/4/4/3/3/2/2/1/1 格），船隊沒有跟著棋盤放大，海域比例上空曠很多；最後那艘 1 格的「幽靈船」不佈署，等前 9 艘全沉才登場、對手落彈紀錄全部作廢（所有合法位置會發紫光，不用用猜的）。第一回合與每開 **10 槍**，從 3 個隨機強化裡選 1 個，共 **25 種**、分銀/金/稜鏡三階（銀最常見、稜鏡最稀有）。主動技能在右側「⚡ 海克斯」分頁按使用（部分技能點擊時按住 `Shift` 可切換成直行/橫列）。棋盤放大後 Excel 偽裝**整個停用**（放不進 10 欄試算表的隱喻），`Esc` 改跳 VSCode 遮羞布；每次出手畫面中上方會跳動作提示，不用一直盯戰報；戰報裡的強化名稱滑過會浮出效果說明。一場約 **34–44 分鐘**（經典模式 8–10 分）
  - *偵察*：海克斯聲納／初級聲納（各自獨立額度，3×3 掃有無，消耗回合）、內線情報（立刻揭露敵方一格）、深海雷達（落空時提示 1 格內/2 格以上）、局部探測（整條橫列/直行掃有無，消耗回合）、航海日誌（連續 3 次落空自動標 1 格確定沒船，每局 2 次）
  - *火力*：乘勝追擊（命中連鎖，舊版無限／新版封頂 2 發）、十字爆破（一發打 5 格）、機率補償（連 4 落空後加送 2 發）、重型火砲（放棄常規開火改轟 2×2 共 4 格）
  - *防禦*：幽靈艦隊／誘餌浮標（假船，3 格或 1 格，共用同一個欄位）、緊急躍遷（移動未受損的船，消耗回合）、反應裝甲（航母每格要打兩次）、艦隊重編（不消耗回合，平移未受損的船 1 格）
  - *稜鏡*：背水一戰新舊版（剩 1 艘時每回合 2 槍，新版額外隨命中自癒 1 格）、同歸於盡（船被擊沉時反擊 1 發必中）、艦隊重組（未受損的船全部換位，消耗回合）、戰爭狂熱（每沉一艘敵艦永久 +1 基礎開火）、無畏號裝甲（旗艦前 2 次命中判定跳彈）、軌道打擊（放棄開火換整條線全部翻開視為命中）、**虛式「茈」**（只有剩最後 2 艘船時才可能刷到；消耗回合，以一列為中心的 4 列共 40 格全開火，發動時雙方畫面播放專屬過場動畫，`Esc` 可跳過）、**浪漫168突襲**（放棄開火，隨機偷走對手一張已擁有的強化，發動時雙方畫面跳出專屬圖片）
- **上班模式（Excel，可玩，僅限經典 10×10）**：按 `Esc`（或頂欄 📊）變成一張 Q3 業績試算表，分頁標題與 favicon 一起換、自動靜音。左表 Forecast = 敵方海域、右表 Actual = 我方（淡藍填色是船）。**方向鍵移動、Enter 開火**，滑鼠點兩下同一格也行。命中 = 紅字負數、落空 = `-`、擊沉 = 淺紅填滿深紅字。狀態列左邊 `Ready` = 輪到你、`Calculating…` = 等對手；右邊 `Sum` = 對方沉幾艘、`Count` = 我剩幾艘。擺船階段游標在 Actual 表上：方向鍵移動、淡藍虛線框預覽目前這艘船（放不下變紅）、**Space** 旋轉、**Enter** 放下（自動換下一艘）、**Delete** 撿起游標下的船、`F9`（Excel 重算鍵）= 隨機部署；五艘都放好後 Enter = 準備完成。滑鼠：點一下選格、再點一下放。終局跳 Excel 風格對話框，OK = 再來一局
- **上班模式（VSCode，純遮羞布）**：頂欄 💼。假 VSCode，輪到你時狀態列錯誤數從 `⊗ 0` 變 `⊗ 1`。任何一種模式按 `Esc` 回來

## 本機試玩

```bash
npm start          # 開在 http://localhost:8080
```

或任何靜態伺服器都行（`python -m http.server 8080`）。
`file://` 直接開不行 —— ES module 要 http。

## 部署到 GitHub Pages（免費、公開連結）

```bash
cd battleship
git init
git add .
git commit -m "battleship p2p"
gh repo create battleship --public --source=. --push
```

然後到 GitHub repo → **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save。
一分鐘後網址是 `https://<你的帳號>.github.io/battleship/`。

沒裝 `gh` 的話：GitHub 網頁上建一個 repo，再 `git remote add origin ... && git push -u origin main`。

## 怎麼玩

1. 房主開頁面 → 輸代號 → **開新房間**
2. 點頂欄的房間碼 🔗 複製邀請連結，丟給朋友
3. 朋友點連結 → 房間碼自動填好 → **加入**
4. 兩邊各自擺船 → **準備完成** → 隨機決定先手 → 開打
5. 想看戲的人用同一個連結，勾「以觀戰身分進入」

## 架構

```
index.html      畫面骨架
style.css       深海雷達風
js/game.js      純規則：擺船合法性、命中判定、回合邏輯（無 DOM、可單獨測）
js/net.js       PeerJS 連線層，host 當 hub 轉發，觀戰者掛在 host 上
js/audio.js     Web Audio 合成音效
js/ui.js        DOM 渲染
js/main.js      狀態機 + 訊息路由 + 互動
```

判定方式是「各自判定自己的棋盤」：對方只知道你回報的命中/落空，看不到你的船位。
反過來說，改程式碼的人可以謊報結果 —— 這是 P2P 沒有裁判的天生限制，跟朋友玩夠用了。

## 已知限制

- 配對靠 PeerJS 公開 signaling server（`0.peerjs.com`）。它偶爾會抽風，重整再開一次房通常就好。
- 某些公司網路 / 嚴格 NAT 會擋 WebRTC 直連。PeerJS 預設有 STUN 但沒 TURN，過不去就是過不去。
- 玩家中途斷線，這局作廢。重新用連結進房會直接開新局。
- 兩位玩家以外的人只能觀戰。
