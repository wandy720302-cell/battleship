        📖 使用教學

        快速開始

        1. 輸入代號，按 開新房間
        2. 點頂欄的房間碼 🔗 複製邀請連結，丟給朋友
        3. 朋友點連結 → 房間碼自動填好 → 加入
        4. 兩邊各自擺好五艘船，按 準備完成
        5. 隨機決定先手，開打。把對方五艘船全打沉就贏

        房主可以在擺船階段勾「命中後可以再開一槍」，會即時同步給對手。

        擺船

        點船塢的船 → 點棋盤放下（自動跳下一艘）
        從船塢拖到棋盤放下
        R、右鍵、⟳ 按鈕旋轉（已放的船就地轉，轉不進去會退回）
        點棋盤上的船撿起來重擺
        🎲 隨機部署一鍵全放
        ↺ 全部收回清空重來

        五艘：航空母艦 5、戰艦 4、巡洋艦 3、潛水艇 3、驅逐艦 2。船不能重疊，可以相鄰。

        對戰

        • 輪到你時，上方橫幅變青色、敵方海域亮起，游標變準星
        • 點一格開火。✕ 命中、● 落空、紅底 擊沉
        • 金框是最新一發，戰報在右側即時更新
        • 連射規則開啟時，命中可以繼續開火，落空才換人
        • 終局會揭曉雙方船位；按 再來一局，對方也按了就重新擺船

        聊天與觀戰

        • 右側面板切到 聊天 分頁；有新訊息會亮小圓點
        • 想看戲的人用同一個邀請連結，勾「以觀戰身分進入」，可以看兩邊海域和聊天，不能出手
        • 一間房只有兩位玩家，第三個人進來會被要求改觀戰

        上班模式 · Excel（可以在裡面打）

        按 Esc 或頂欄 📊，整頁變成 Q3_Forecast.xlsx，分頁標題、favicon 一起換，自動靜音。再按 Esc 回來。

        怎麼看

        • 左表 Forecast = 敵方海域，右表 Actual = 我方（淡藍格是船）
        • 命中 = 紅字負數、落空 = -、擊沉 = 淺紅底深紅字
        • 狀態列左邊 Ready = 輪到你、Calculating… = 等對手
        • 右邊 Sum = 對方沉幾艘、Count = 你剩幾艘

        擺船（游標在 Actual 表）

        方向鍵移動，虛線框預覽這艘船；擺不下變紅
        Space旋轉
        Enter放下（自動換下一艘）；全放好後 = 準備完成
        Delete撿起游標下的船
        F9隨機部署

        對戰（游標在 Forecast 表）

        方向鍵移動綠框
        Enter開火
        滑鼠點一下選格、再點一下開火

        終局會跳一個「Microsoft Excel」對話框，OK = 再來一局。Ribbon 的 Help 分頁裡也有這份快速鍵表，在偽裝裡查不會破功。

        上班模式 · VSCode（純遮羞布）

        • 頂欄 💼 進入，看起來在寫 NestJS。分頁、檔案樹可以點
        • 只能偷看回合：輪到你時，狀態列的錯誤數從 ⊗ 0 變 ⊗ 1
        • 要出手得按 Esc 回來，或改用 Excel 模式

        疑難排解

        • 連不上 / 找不到房間：配對靠公開的 PeerJS 伺服器，偶爾抽風，房主重整再開一次房。公司網路擋 WebRTC 的話換網路
        • 對手斷線：這局作廢。對方重新用連結進房會直接開新局
        • 沒聲音：瀏覽器要先有點擊才准出聲；看頂欄 🔊 有沒有被關掉。上班模式會自動靜音
        • 手機：可以玩，擺船用點的比拖的順
